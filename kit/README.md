# Official student kit

Put the Samsung student kit files here (`supported_classes.json`, `validate.py`,
`manifest.csv`, example outputs). This folder is git-ignored until we confirm the
kit may be published in this public repository (see `docs/kit_checklist.md` #9).

`code/vocab.py` reads `kit/supported_classes.json` by default; set
`ACTIVA_VOCAB=/path/to/supported_classes.json` to use another location.

# M2 - Perception (CLIP, importance, category)

Branch: `m2-perception`.
Owns: `code/clip_features.py`, `code/importance.py`, `code/category.py`,
`code/category_vocab.py`, `code/clip_backend.py`, `code/tcn.py` and the other
`perception_*` / `fpvsum_*` / `leakage_*` modules, M2 scripts and tests,
CLIP/TCN weight docs.

Interfaces:

- `clip_features.extract_clip_features(info) -> ClipFeats` on the `CLIP_FPS` grid.
- `importance.predict_importance(info, clip) -> Importance` on exactly `clip.times`, values in [0, 1].
- `category.classify_video(info, clip, imp) -> CategoryResult` with a label from `vocab.load().categories`
  (the kit's 16 labels: 14 FPVSum categories + `cooking` + `other`). The JSON's
  `label.score` is `scores[label]` clipped to [0, 1], so make `scores` a
  calibrated confidence (for example a softmax), not a raw cosine similarity.

What `main.py` does with your output: checks shapes, grids and ranges. An
exception or invalid output means a fallback (empty features, flat 0.5
importance, first category).

Shared files you started (`contracts.py`, `config.py`, `video_io.py`) are now
M4-owned on `main`; your behaviour is kept (see `docs/decisions.md` D2-D4).

Landing on `main`: see `docs/integration_plan.md`.

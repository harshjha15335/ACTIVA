# M3 - Selector and Evaluation

Branch: `m3-selector`.
Owns: `code/candidates.py`, `code/optimizer.py`, `eval/`, ablation scripts,
`tests/test_budget.py`, `tests/test_intervals.py`, `tests/test_metrics.py`.

Interface: `optimizer.select_highlights(info, actions, imp, clip) -> list[Highlight]`,
sorted, non-overlapping, `0 <= start < end <= duration`, importance in [0, 1],
every clip at least `config.MIN_CLIP_SECONDS` (4.0 s: the scorer ignores shorter
ones), total at most `config.BUDGET_RATIO * duration` (aim for `config.BUDGET_SAFETY`).
Videos where 15% is under 4 s (3 in the manifest): return exactly one 4.0 s clip.

What `main.py` does with your output (`normalize_highlights`): rounds clips
inward to 2 decimals, drops clips under 4 s (logged), merges clips that touch,
then checks the rules above. Overlap, bad types, an exception, an empty result
or an over-budget result means the uniform fallback (6 s clips) is used instead.
Highlights in the JSON carry only `segment`; importance stays internal.

Landing on `main`: see `docs/integration_plan.md`.

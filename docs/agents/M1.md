# M1 - Action Engine

Branch: `m1-actions`.
Owns: `code/actions.py`, `code/action_config.py`, `code/slowfast_features.py`,
action weights docs, `tests/test_actions.py`, `kaggle/`.

Interface: `actions.detect_actions(info: VideoInfo) -> list[Action]` with every
action in the full video. `verb`/`noun` must be exact vocabulary strings and a
valid pair; `0 <= start < end <= info.duration`; `score` in [0, 1].

What `main.py` does with your output: drops actions with unknown verb/noun,
invalid pairs or non-finite values (logged), clamps times into the video. If
`detect_actions` raises, the pipeline continues with no actions.

Time origin: seconds from the first decoded frame (`code/video_io.py`).
Decode frames with `video_io.iter_frames`, or document how your own decoder
matches that origin.

Landing on `main`: see `docs/integration_plan.md`.
